 Amazon Sales Analysis Dashboard
Project Overview:
This project is an interactive "Amazon Sales Analysis "Dashboard" developed using "Microsoft Power BI". The dashboard analyzes Amazon sales data and presents important business insights using interactive charts, KPI cards, slicers, and data visualizations.

The main purpose of this project is to transform raw sales data into meaningful insights that help understand sales performance, profit, product categories, cities, discounts, and shipping methods.

Project Objectives:
- Analyze overall Amazon sales performance.
- Calculate total sales, total profit, and total quantity.
- Compare sales performance across different cities.
- Analyze profit based on product sub-categories.
- Identify monthly sales trends.
- Compare product category performance by month.
- Analyze the relationship between discounts and sales.
- Understand customer orders based on shipping modes.
- Create an interactive and user-friendly Power BI dashboard.

Dashboard Features:
The dashboard includes the following visualizations:

Sales by City:
1.This bar chart compares Amazon sales across different cities such as:
- Mumbai
- Bengaluru
- Chennai
- Delhi
- Kolkata

2. Sub-Category Profit Analysis
This line chart displays the profit generated by different product sub-categories.

3. Monthly Category by Sales
This chart compares monthly sales performance across different product categories.

4. Discount by Sales
This gauge visual shows the relationship between discount values and total sales.

5. Category Ranking by Month
This visual compares category sales performance for each month.

6. Orders by Ship Mode
This donut chart displays the distribution of orders based on different shipping modes.

7. Interactive Filters
The dashboard contains the following slicers:
- City
- Sub-Category
These filters allow users to interact with the dashboard and view detailed insights.
